游戏厅（坦克大战 · 奶龙版 + 五子棋）· 手机浏览器版
=====================================================

整个游戏厅只有一个文件：arcade.html
直接用手机浏览器打开它，先看到首页，点卡片进游戏。
（本地玩法不需要服务器；只有五子棋联机需要跑服务器）


一、坦克大战（单机）
--------------------
· 进入后建议把手机横过来（竖屏会提示旋转，也可以选「仍要竖屏玩」）
· 操作：左下方向键移动、右下红键开火、右侧按钮暂停/重开
· 内容：奶龙背景、四种补给掉落、黑化奶龙 Boss（第 2 波起，三向散射）


二、五子棋
----------
同屏双人：一台手机两个人轮流点，支持悔棋。

联机对战（邀请好友）：
  1) 电脑上双击 start-gomoku.bat（需要 Node.js）
  2) 窗口里会显示：  手机:  http://192.168.x.x:8765
  3) 两台手机连同一个 WiFi，浏览器打开这个地址
  4) 点「五子棋」→「联机对战」→「创建房间」，得到 4 位房间号
  5) 点「复制邀请链接」发给好友（微信/QQ 都行）
     好友点开链接会自动进入游戏厅并加入这个房间
  6) 黑棋先手，双方落子实时同步，服务器负责判定胜负与轮次


三、常见问题
------------
· 手机打不开电脑地址
  - 确认手机和电脑在同一个 WiFi（不是移动数据）
  - Windows 第一次运行会弹防火墙提示，选「允许访问」
  - 电脑 IP 变了就看服务器窗口里新打印的地址

· 想让不在同一 WiFi 的朋友玩
  - 用 cloudflared / frp / ngrok 把 8765 端口映射到公网，把映射地址发给他
  - 或把 arcade.html + gomoku-server.mjs 放到任意支持 Node 的服务器上：
        PORT=80 node gomoku-server.mjs

· 手机打不开 .html
  - 安卓：文件管理器里点它 → 选择 Chrome 打开
  - 苹果：存到「文件」App → 用 Safari 打开

· 断线
  - 被邀请方刷新页面会自动回到原座位（链接里带房间号）
  - 房主刷新需要重新创建房间


文件说明
--------
arcade.html        游戏厅本体（坦克大战 + 五子棋，单文件，113 KB）
gomoku-server.mjs  五子棋联机服务器（零依赖，Node.js 18+）
start-gomoku.bat   Windows 一键启动服务器
